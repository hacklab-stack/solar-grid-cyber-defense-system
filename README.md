# ☀️ Solar Grid Cyber Defense System

A  cybersecurity platform designed to monitor solar energy systems and protect them from cyber threats.


### 🚀 What it does
- Monitors solar sensors (Voltage, Current, Power) in real-time
- Detects abnormal behavior / potential cyber attacks
- Triggers alerts and defense mechanisms to guard the system

### 🛡️ Security Features
- Anomaly Detection for sensor data
- Attack simulation & guard system
- Secure data handling

### 💻 Tech Stack (Conceptual Phase)
- Frontend: HTML, CSS, JavaScript
- Future: ESP32 + AWS IoT Core
